# Code of conduct

<PROJECT> follows the
[Contributor Covenant, version 1.4](https://www.contributor-covenant.org/version/1/4/code-of-conduct/).
It applies within all project spaces, and in public spaces when someone
represents the project or its community.

## Resolve conflicts

Healthy debate and disagreement are welcome; disrespectful behavior is not.

If you see someone violating the code of conduct, we encourage you to address
the behavior directly with the people involved when it's safe to do so. If you
can't resolve the matter, or if the behavior is threatening or harassing,
report it to <CONDUCT_CONTACT_EMAIL>.

We look into every report. We don't share the reporter's identity with the
person reported. Depending on what we find, our response ranges from no action
to a permanent ban from the project and its spaces.
