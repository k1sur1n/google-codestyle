## 2. Атрибуция (требование CC-BY)

Тексты google/styleguide и eng-practices распространяются под Creative Commons Attribution 3.0 Unported. Профиль выполняет требование атрибуции так:

> Правила профиля основаны на Google Style Guides (© Google, <https://google.github.io/styleguide/>; редакции: Python - 2026-09-10, C++ - 2026-09-29, остальные - по датам в строках «Источник») и Google Engineering Practices (© Google, <https://google.github.io/eng-practices/>), лицензия CC-BY 3.0 (<https://creativecommons.org/licenses/by/3.0/>). Текст пересказан и переведён на русский; дословные фрагменты перечислены в `NOTICE.md`. Google не участвовал в подготовке профиля и не одобрял его.

Для материалов CC BY 4.0 (opensource.google, developers.google.com, angular.dev, Google Cloud, tuning_playbook, oss-vulnerability-guide) действует та же формула с указанием конкретной страницы; изменения (пересказ, перевод, адаптация шаблонов) названы в разделе 3. Для материалов Apache-2.0 указаны источник и лицензия; файлов `NOTICE` у исходных репозиториев нет. Для CC BY-NC-ND 4.0 (книга SWE) производных текстов не создано: только пересказ со ссылкой.

Что считается пересказом: правило сформулировано своими словами на русском по смыслу источника, со ссылкой на раздел; примеры «плохо / хорошо» написаны для профиля заново, из источников в них взяты только короткие идентификаторы-образцы, перечисленные ниже. Конфиги профиля (`pyproject.toml`, `.clang-format`, `.clang-tidy`, `eslint.config.js`, `.stylelintrc.json`, `.editorconfig`, `.pre-commit-config.yaml`, CI) составлены заново; совпадающие с источниками значения опций и скопированные фрагменты конфигураций тоже перечислены.

Проверено 2026-10-09 (клон `PAIR-code/datacardsplaybook`, HEAD `9c6545b`, последний коммит 2023-02-22; сайт - WebFetch):

- `README.md` репозитория: «The Data Cards Playbook is licensed under a Creative Commons Attribution-Share Alike 4.0 International License».
- Футер сайта <https://sites.research.google/datacardsplaybook/>: та же формулировка, CC BY-SA 4.0; Apache 2.0 на сайте не упоминается.
- Файл `LICENSE` в корне репозитория: Apache License 2.0.

Итог: расхождение подтверждено. Авторы объявляют лицензией **содержимого Playbook** CC BY-SA 4.0 (две независимые публикации), а файл Apache-2.0 относится к репозиторию в целом (обычная практика для кода и шаблонов в репозиториях Google). Для содержимого правильнее исходить из CC BY-SA 4.0.

Что это значит для профиля. `templates/ml/DATA_CARD.md` берёт из Playbook только названия 16 тем в их порядке; подпункты и подсказки написаны заново, раздел 17 добавлен профилем. Названия разделов сами по себе - минимальное заимствование, но если считать шаблон производным произведением от материала под CC BY-SA 4.0, на него распространяется условие share-alike: файл `templates/ml/DATA_CARD.md` и его копии в проектах пользователя должны распространяться под той же лицензией CC BY-SA 4.0 с указанием источника. Профиль принимает эту осторожную трактовку: атрибуция в шапке файла уже есть; пользователь, которому share-alike не подходит, может заменить названия тем своими формулировками - тогда зависимость от Playbook исчезает. На остальные файлы репозитория это условие не распространяется.
